# Changelog

## 0.1.0

First release.

- Sign in through the browser (the same flow as `shk auth login`), with an API token, or to a self-hosted server.
- Live feed in the sidebar: expand an endpoint to stream its webhooks as they arrive.
- Open an event as a read-only JSON tab with its headers, query and body.
- Replay an event to your local server, with a fixed / regressed verdict and the result saved to the dashboard's replay history.
- Copy an event as a fixture, or generate types, a fixture and a test in TypeScript, Python, PHP or Go.
- Status bar count of new webhooks.
